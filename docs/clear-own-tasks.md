# 清除本人当前会话工单任务

- `清10`（也可`清 10`）：停止追踪当前会话本人的短号10，从待办移出，随后填/完不能再处理它；已完成或已取消任务提示无需再次清除。
- `清全部`：完整预览当前会话本人所有未完成待办（不限待办列表显示的10条），以及1条可能未编号的待补充任务。
- 5分钟内回复`确认清全部`：仅在当前清单未变化时执行。其他用户、群和私聊不能使用这次确认；过期、重复或任务变化时须重新预览。

清除是停止本地追踪，不是抹除历史：保留取消状态防止旧短号和重启续跑；不删除飞书记录、腾讯已写草稿、业务查重或消息防重记录，也不清除本人身份。单条不改其他待补充任务；批量确认后清掉本会话待补充及工单续聊指针。

正在处理、排队或本地状态为processing时拒绝清除，不强行中断已开始的在线写入。网关在排入worker队列前先拒绝忙碌的清除请求；worker再次检查。待办太多无法完整展示确认范围时不执行，改用指定短号逐条处理。

这是用户明确新增的本人业务操作；源文件修改、清空全局队列、取消他人任务、/cancel及其他管理指令仍禁止。只在企业微信入口将短口令转换为内部/forget协议，权限检查后执行。HELP_ENTRIES与菜单同步。

只使用本地状态，无新增模型/网络API/后台任务/固定费用，月流量未实测。离线测试使用合成状态和本机克隆；用户实际确认清除及后续待办查询已有回执。保留、过期、权限、重放等边界以合成状态验证，不扩大到其他用户真实任务。

确认顺序：先点“保留待办”只撤本次未执行确认；先点“确认清除”后再点“保留待办”不能撤销已执行操作。已消费的确认不重复执行，不恢复或重放任务。
