# 项目状态与验收边界

更新：2026-11-03。对应当前修复分支，不代表默认分支已合并或其他电脑已部署。本页不保存账号、人员、工单、表格标识或聊天原文。

## 仓库边界

本仓库是可公开的集成源码，包含独立排班入口、现代工单网关和嵌入worker；只发布通用代码与脱敏说明。实际运行配置、状态、表格数据、日志和统计不进入Git。

## 已实现

- 排班与工单独立角色、独立凭证/状态/端口/启动任务；每实例一个主进程和一个守护。
- 本人身份与任务按发送者、会话隔离，群聊/私聊分开；短口令、角色菜单及限定当前人的按钮。
- 排班07:00当天、17:00次日，发送前读最新表；即时个人视角、只读请假候选和岗位限制。
- 绑定动力人员白班16:30、夜班次日07:30私聊模拟交班草稿；不把模拟措辞当真实完成证据。
- 普通工单按配置飞书填写/核验/提交；确认后由“完+短号”生成固定腾讯草稿。动力只建飞书、两个人员字段空白。
- 已有记录卡保护、目标核对、组合单号查重、未知结果禁止盲目重试；草稿整行检查、备份、追加与读回，已有交接行本机确认。
- 清指定/全部本人当前会话待办只停止本地追踪，保留防重，不回滚在线记录。
- 登录后启动、异常退避恢复、连接检测、日志轮转；匿名统计生成本地问题摘要和规则建议，不自动修改上线。

这些功能属于集成系统的范围，不能据此认定每个独立仓库的旧入口都具备全部能力。

## 待验收

1. 新真实普通工单闭环和动力/异地等角色正向场景；模糊姓名、单号和厂商仍需确认。
2. 多成员并发提交、分别补充及跨会话隔离的真实试用。
3. Windows重启登录、真实断网恢复、浏览器登录失效、长时间运行；避免打断正在使用的远程连接。
4. 动力交班提醒在自然班次的私聊送达和统计准确性。
5. 一分钟登记目标及独立测试表连续10次验收；目前不承诺P95或成功率达标。
6. 匿名统计积累真实样本后审查建议；处理器返回、需补充、保护拦截与已核验登记分开统计。

## 保留的业务限制

图片为来源，OCR是辅助；不能猜姓名、单号或把打卡地点当工作地点。排班只读，腾讯正式表不自动改。普通工单依旧使用已确认的收到时间推算完成/结束规则；推算不是已核实实际时间，本轮不改变规则。

身份不授予权限。菜单、授权、源文件、进程和群绑定的维护边界见相关说明；结果不明先核验，不以重发或改短号绕过保护。

## 成本

无新增云托管或统计模型费；排班、按钮、守护与本地规则汇总不调用模型。识别、开发和调试仍占已有模型额度、本机资源与网络；月度模型消耗、代理流量及电费未实测。事件容量约6MiB/实例，不等于整个服务免费。
