# 按月查询请假调休候选日

已绑定身份的成员可以直接问排班机器人：`我哪几天可以用来请假调休`。这会查询本人本月剩余日期（含今天至月底），一次列出候选工作日、原表已休、命中限制及待核对日期。

## 命令与范围

- `请假候选`或`调休候选`：默认本月剩余日期。
- `请假候选 本月`：今天至月底。
- `我下个月哪几天可以请假`或`调休候选 下月`：下月整月，需排班已发布。
- `调休候选 2026-11`：指定月份整月；含已过日期时仅供排班回看。
- 群聊需@排班机器人，私聊直接发送；先绑定`排班身份 本人准确姓名`。仅使用当前会话本人的绑定，不接受他人姓名参数。

候选条件仅为原排白班且未命中已确认的夜班（含动力夜班）、白班主值和配置异地网络1限制。原表明确标注调休、休息、休假等日期单列，不充当新请假日；空白或无法完整核验的日期留待核对，不自动推断全天可休。候选不等于批准，不办理申请，也不检查假期余额。

选好后可以发送`请假检查 YYYY-MM-DD`复查当天最新排班。月表会变更，查询结果不是后续调班的永久保证。

## 读取、准确性和成本

同月共用一次读取与二次一致性核验，通常5次只读API请求，不是逐天读取31次。一个日期缺失、重复或岗位冲突只影响该日期，其他日期仍有结果；整月读取或颜色发生变化则停止，不用缓存替代。

CSV读取可选保留空行，排班使用真实物理行位置核对颜色，其他CSV调用默认行为不变。相关回归覆盖自然问句、本人绑定隔离、无效月份、月末/闰年/跨年、缺行/重复及空行后的颜色，分类合计覆盖查询范围内每一天。

无新依赖、后台任务、付费服务或模型调用；新查询使用已有平台权益、本机资源和网络。额外API额度、月度流量及金额未实测。公开示例使用合成数据，真实个人排班结果仅存本机。
