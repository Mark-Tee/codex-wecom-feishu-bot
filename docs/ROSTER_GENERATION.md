# 月度排班模块

这是现有排班机器人的可选模块，不是新机器人服务。默认关闭，不影响原有排班查询。代码仅生成本地审核草稿，不自动发布在线表，不代办加班、请假或调休。

## 启用与使用

在现有机器人配置的 `roster.generation` 中设置：

```json
{
  "enabled": true,
  "ownerUserId": "maintainer-user-id",
  "python": "python",
  "node": "node",
  "outputDir": "./roster-output"
}
```

`ownerUserId` 必须是已被当前机器人授权的固定账号，不通过聊天自报姓名授予生成权限。输出目录须是本机可写路径；需要集中存储时指定自己的磁盘位置。不要提交实际配置、账号、班表或读取凭据。

发“菜单”后，维护者可点“生成排班稿”；文字口令 `生成排班稿 [YYYY-MM]` 默认下月，例如 `生成排班稿 2026-12`。参数非法、无权限、并发生成、源数据不完整时拒绝。帮助同时覆盖按钮、参数和限制。

Excel中，在本人当天班次格填写准确文字“调休”，岗位姓名与次数联动扣除；多人岗位仅去除本人，不自动补岗。改回原班次恢复。岗位列为公式，不能用纯数值粘贴替代。手动换岗不在本次联动范围内。

## 规则与范围

- 首版支持已核验的2026年日历、两个部门共15名成员以及现有29列模板；成员和业务表来源仍来自本机业务配置，不写入仓库。
- 每部门每日白班主值、夜班主值各1人；白班主值不得连续两个自然日，含跨月。上月最后一天的主值和夜班名单必须经源表文字和颜色核对。
- 夜班当天不排白天工作，次日休息。普通工作日其余人员安排异地岗位，不为压低工时自动排休。每岗1/2最多各1人，3承接其余人员。
- 辅值仅非节假日周一至周五；官方周末补班无辅值。异地岗位仅官方工作日。
- 动力白班、夜班各1人，从相应主值中选择，是唯一允许的兼岗。
- 白班计1工时、夜班计2工时，是业务单位而非实际小时。月度至少达到工作日数，无超额上限；先均衡总工时，再均衡岗位次数。CP-SAT限时45秒，可行解不冒称全局最优；无解和超时分开反馈。
- 休息日绿色、主值黄色、夜班浅蓝、调休红色，另保留岗位与汇总配色。数据中心3列宽120像素，允许双人姓名；其他列按模板紧凑显示。

## 在线月表保护

生成前读取在线月表列表；已有同月表时仍只输出独立Excel，并提示未替换在线表。发布需单独授权。集成代码须调用 `createOnlineMonth(client, file, month)`：写入前重新读列表，同月表存在或列表无法核验即拒绝，不能清空、重命名、覆盖或自动删除来绕开。只有用户自行删除在线同月表后才允许新建。创建入口只建立空白月表，不承担Excel上传和格式迁移，不能把创建成功当作发布完成。

生成中状态本地持久化；恢复运行后继续同月请求。已经完成的任务不重复执行。导出前独立校验岗位、工时、休息和跨月约束；导出后重新导入、比对公式结果，并实际修改调休状态检查姓名和统计联动，再恢复测试值。

## 依赖、安装与验证

1. Node.js 22+，以及与OR-Tools wheel匹配的Python（本次验证3.14）。
2. `python -m pip install --target vendor/roster-python -r scripts/roster-requirements.txt`。
3. 已安装并授权的Codex Desktop表格运行时：`@oai/artifact-tool`。此库没有随仓库分发，也不假设能从公共npm安装。由运行时依赖加载器定位其 `node_modules`，在本机配置模块解析路径；缺少该运行时就不能完成Excel导出。不要提交依赖目录或创建指向他人机器的路径。
4. 现有worker模块：`src/providers/tencent-docs/client.mjs`、`schedule-broadcast.mjs`及其核心依赖；由 `roster.rulesRoot` 指向。读取凭据通过当前环境提供，不写入配置示例或仓库。

验证：`node --test tests/*.test.cjs`；`python tests/roster-solver.test.py`。公开镜像还运行完整worker测试与敏感扫描。导出器自身运行真实工作簿调休、多人保留、公式、重导入检查；仅Node单元测试通过不代表外部Excel运行时可用或在线发布已验证。
