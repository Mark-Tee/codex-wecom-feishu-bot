# 共享飞书单条测试保护

`feishuBrowser.writeApprovalFile` 为可选的本机许可文件绝对路径。未配置时沿用原业务模式；开启后图片仍可识别并保存待办，但缺少匹配许可时不会打开浏览器或写表，腾讯草稿更新暂时拒绝。

许可只允许 `create-one`，绑定目标origin/base/table、工单字段（包括原日期）、会话、发起人、使用人和收单时间的SHA256指纹，并要求有效期。许可由维护者在本机核准，不能从群中生成。核准前须只读检查原单日期、重复单号、目标表与新建位置，不能只凭显示名称判断目标。

许可在打开浏览器前以独占创建的 `.used` 文件消耗。网络失败、超时、崩溃和未知提交结果均不自动恢复许可；禁止直接重试或删除许可占用文件来绕过核验。需先只读核对实际结果，并取得新增记录的相应授权。已有记录卡拒绝复用，切换视图后发现记录卡同样拒绝；新建表单关键文本字段必须可核验为空。填字段和提交前再次核对目标表。

提交成功提示不等于完成共享表验收。还须读回核对新增记录及字段，确认没有额外新增或改动已有记录；不能把其他协作者的同期变化自动归因于机器人。这道本机门禁限制本机器人一次尝试，并非全表分布式事务或多人并发唯一性承诺。

测试完成后由维护者明确决定是否退出保护；不得自动取消保护、恢复许可或清理测试记录。删除测试记录须另获确认。许可、占用文件、任务指纹和真实数据仅留本机，不提交Git。

成本：门禁和指纹在本机执行，无模型调用、无额外网络轮询。识别工单沿用现有模型消耗；实际写入验收前不扩大批量测试。
