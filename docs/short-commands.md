# 短口令

企业微信入口将完整短口令转换为既有命令，worker沿用原协议。群聊先@对应机器人，私聊直接发送；旧命令继续有效。

|机器人|短口令|作用|
|---|---|---|
|排班|班、今、明|今天明天、仅今天、仅明天|
|排班|休、休下月、休2026-12|本人本月剩余或指定月请假候选|
|排班|休今、休明、休2026-11-04|本人单日请假限制检查|
|排班|我、我 姓名|查看或设置当前会话本人身份|
|排班|推送、交班|排班推送状态、本人动力交班提醒状态|
|工单|单、继续|本人待办、待确认信息|
|工单|人 姓名|设置当前会话本人使用人|
|工单|补 内容|补充当前待确认工单|
|工单|填12、完12|重试填报、确认提交后生成腾讯草稿|
|工单|清10、清全部|停止本人当前会话指定任务追踪；全部先预览确认，不回滚在线记录|
|两个|菜单、状态|帮助及运行状态|

填与完后须给1到8位数字短号，可带空格（如填 12）；身份与补充必须有空格。例：我 测试甲、人 测试甲、补 09:00。只转换完整指令；普通文字不截断、不推断意图。

权限、会话身份隔离、查重和源表只读限制不变。休只查候选或岗位限制，不办理请假；完必须先确认飞书提交，仅现有固定腾讯草稿，不自动修改正式腾讯表；动力或异地无需此操作。没有文件删除或全局管理短口令；清理仅停止本人当前会话追踪，不是在线记录删除。没有新模型调用、API请求、依赖或固定费用，月流量未实测。
