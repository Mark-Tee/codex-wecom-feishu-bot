# 机器人回复精简

排班仅展示个人岗位、各站点人员、班次时间和读取时刻，不逐日重复请假限制。请假结果保留候选、已休、受限、待核对四类日期和数量；休息类型仅在展示时省略重复来源括注，原始分类与依据不变。单日检查保留结论、冲突及核对指引。

两个菜单只列现有指令、参数、例子和必要限制。成功工单回执保留提交状态、飞书任务号、本地短号和下一步，不再罗列已填字段；异常及结果不明仍保留核验指引。动力草稿保留模拟标记、统计截止时刻、模板正文、待核对任务与交班前复核提示。没有增加命令、依赖、模型调用、API请求、定时任务或固定费用；流量未实测。

仅修改显示，路由、权限、自动提交、业务查重、岗位判断、绑定及写表范围不变。真实消息显示待使用者确认，不能把本地样例当成实际送达。
