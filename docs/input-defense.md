# 机器人输入与本机防御

更新：2026-11-04，适用于已拆分的roster/ticket部署。此页描述应用入口防护，不代表完成Windows系统级隔离或公网渗透测试；历史combined/旧bridge入口不能据此宣称已加固。

## 边界与限额

- 在下载、OCR、模型和排队前检查发送者授权、消息类型、身份/会话字段及内容长度。个人身份不代替授权。
- JSON解析上限256KiB，拒绝危险原型键和畸形对象；文本最多16KiB，混合消息最多12段、4张图片。
- 每人20次/分钟、每实例60次/分钟；同时处理最多4个入口请求，其中媒体最多2个；工单等待队列最多10条。拒绝提示每人最多10秒一条，避免刷屏。
- 新增的临时防重与限流只保留有界内存，不采集正文或账号到统计文件；既有持久化消息防重和业务查重继续保留。
- 未知/越权命令拒绝；Unicode全角和零宽变体在权限检查时归一化。填/完/清的参数须完整匹配，不能附带其他命令。待确认任务不存在时“是/不是”不能落入通用模型执行。

限额会拒绝异常高频、超长或超量请求，不把它们悄悄截断成另一条工单。需要调整限制时由本机维护核对真实使用量，不自动放宽。

## 图片下载

仅HTTPS、不含用户名密码、标准443端口；禁止跳转。解析所有DNS结果，任何内网/回环/链路本地/保留地址即拒绝，并将已核验地址用于实际连接，防止校验和连接之间重新解析。

每图下载最多16MiB、15秒。只接受PNG/JPEG，头部尺寸最多12000边长且不超过4000万像素；这不是完整图片安全扫描。落盘使用随机文件名，不使用消息编号拼路径。异常下载不继续以残缺图片建单。

没有要求所有图片来自某一个固定CDN白名单，以保留平台合法公网附件的兼容性；URL限制与DNS检查不能代替完整系统网络隔离。

## 工单识别权限

工单图片和所需排班/历史格式上下文由固定业务代码准备；模型只提取数据和询问歧义。识别运行使用read-only，关闭shell、任意本机看图工具、插件、Apps、子代理、搜索、JS及生命周期hooks，覆盖notify为空以避免继承桌面通知命令；原图仍由显式-i附件输入。

先在关闭插件/Apps的配置下枚举MCP，再逐项关闭，最后读回启用清单。不能确认权限或仍有启用项时不启动识别，不回退到宽权限。沿用现有模型/登录，不修改用户全局Codex配置，也不改变为另一个计费模型；关闭非业务个人记忆/目标与技能依赖自动安装，项目指令注入预算为0，只保留显式业务提示与上下文。去掉不需要的企业微信、腾讯和GitHub环境凭证。

飞书/腾讯操作由原固定代码处理，保留目标、身份、查重、字段、整行占用和写后核验。模型返回的数据不是执行命令，不给模型网页写入工具。普通工单的一分钟目标仍需实测，不能因安全检查通过就宣称达标。

## 本机HTTP与异常处理

回环健康/通知接口核对Host，拒绝浏览器Origin和跨站来源，减少跨站及DNS重绑定滥用。通知只接受最多8KiB的JSON、文本最多4KiB、5秒完成；发送前重新确认目标会话用户仍被授权。健康接口保持只读。

解析/消息处理边界分别捕获异常，不用全局uncaughtException继续未知状态；单次失败不能把未确认写入当成功或自动重放。健康busy包含入口请求、工单队列执行，维护时更准确地判断是否可重启。

这不是对本机恶意软件、其他管理员或原生图像解码漏洞的完整防护；仍运行于现有Windows用户。独立低权限账号/虚拟机需要单独设计并验证浏览器登录和业务兼容性。

## 验证与成本

覆盖畸形JSON/对象、超限输入、未授权媒体、伪造按钮键、重复/突发、内网地址变体、DNS混合回答、跳转、下载大小及像素限制、跨站通知和无上下文确认。真实入口用合成事件验证，不向群发送攻击消息、不写真实业务表、不清真实任务。

本机CLI核验关闭后的MCP清单，另做一次合成图片模型检查：启用MCP为0、没有命令执行事件、没有创建测试指令要求的文件，同时正确读取图片。该用例不等于所有提示注入都已穷尽。

本地校验、限流和规则拒绝不调用模型，无新增依赖、云服务或固定月费。每次真实识别增加短时本地CLI权限核验，不增加识别模型请求次数；合法识别依然使用已有额度和网络。测试模型调用实际输入18994 Token（含8832缓存输入）、输出66 Token，未换算为账单金额；月度流量/费用仍未实测。
