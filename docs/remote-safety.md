# 群聊权限与菜单

排班机器人只读源表。工单机器人仅提供固定业务流程；飞书建单、重试提交和腾讯草稿更新仍待独立测试表或实单验收。初期仅离线核验；后续在用户明确授权下完成1条飞书真实新增及读回核验，完整10次验收与腾讯写入仍未完成。

群聊和私聊均禁止管理操作及修改排班源表、文件、配置。维护者在本机维护授权、推送绑定和任务进程；已存在的推送绑定保持有效。个人排班身份与工单使用人属于日常业务设置，不修改源表。

菜单按手机短行分组，移除授权、配对、取消/停止任务、文件删除及绑定入口。只@与 /help 返回对应角色菜单。权限拦截只判断原始消息，不把工单图片中的文字当作操作指令。

成本：菜单和权限匹配均本地执行，不新增模型调用、网络轮询或托管。工单识别与写入沿用原服务；未实测月度流量与模型额度，不能承诺整个服务免费。
