# 群聊、私聊权限与在线写入

更新：2026-11-03。排班源只读；工单只开放固定业务流程。授权、进程、群绑定、源文件/配置修改等管理操作留在本机，历史 `/pair`、`/invite`、`/revoke`、`/stop`、`/cancel`及文件删除不作为当前远程指引。

菜单只展示本角色日常入口。个人排班身份、工单本人使用人和清理本人当前会话追踪是受限业务操作，不授予权限，也不修改源排班表。已有授权、身份和群绑定保存在本机；不要把空allowUsers误解为工单对所有人开放。

按原始消息判断禁止的操作，不把图片/OCR中的描述当远程指令。工单有合法建单权限不等于可以修改在线已有记录。飞书只新建本次记录，目标、字段及查重不完整时停止；腾讯只固定草稿追加，正式来源表不自动改，已有交接行需本机确认。

`清10`/`清全部`仅处理本人当前会话本地追踪，保留防重，不删除在线结果；不得扩展到其他人的任务或全局队列。点击按钮还要核对本人、原群/私聊、角色、有效期及已消费状态。

当前有排班推送、实际按钮结果及限定在线工单测试；新正常工单、多角色和独立测试表连续10次未完成全面验收。以[项目状态](PROJECT_STATUS.md)为准，不把历史单次测试当持续生产许可。

菜单与策略匹配本地执行，无新增模型调用；实际工单仍使用既有额度、网络和本机资源，月度总量未实测。详见[安全验收](order-safety-validation.md)、[清理](clear-own-tasks.md)、[按钮](interaction-cards.md)。
