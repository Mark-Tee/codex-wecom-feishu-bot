# 请假与调休岗位检查

按查询日期的最新排班，命中以下任一岗位即提示不能请假或调休：夜班（含动力夜班）、系统或网络白班主值、配置的异地站点网络1。站点名称从本机配置读取，不在通用源码写入真实站点。夜班按排班表的开班日检查。网络2/3、白班辅值、待命、仅动力白班本身不触发本条限制；未命中不代表请假已批准。

## 使用

先用`排班身份 本人准确姓名`绑定个人身份。群里@排班机器人，私聊直接发送：

- `请假检查`：无日期时查今天。
- `请假检查 明天`或`调休检查 今天`：相对北京时间查询。
- `请假检查 2026-11-04`：参数为真实存在的YYYY-MM-DD日期，只检查当前会话绑定的本人，不接收他人姓名参数。
- `查看排班`等个人查询也显示当天及次日的岗位限制。

本功能仅核对排班岗位并给出下一步，不提交申请、不批准请假、不修改排班。原表空白、存在岗位警告或读取失败时提示待核对，不猜测“可以请假”。名单和颜色按既有只读Provider验证，不能用缓存代替最新在线表。

## 验证与成本

规则覆盖夜班、动力夜班、两部门白班主值、网络1、未命中岗位、空白/警告、跨年日期和无效日期；命令按账号及会话绑定隔离，保持群聊与私聊授权。日期非法时不请求在线表。

复用已有排班读取、日期解析和菜单，无新依赖、后台轮询、服务器或固定月费，不调用模型。一次主动检查通常沿用5次排班只读请求（表信息、两轮数据与样式核验），不新增定时推送；额外网络/已有平台额度及月度流量未实测。本轮GitHub检索现有项目的leave相关实现未找到适用方案，复用现有角色和身份模块。
